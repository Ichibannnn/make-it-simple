# 🚀 [FBTI-HELPDESK]

> A real-time React application built with Vite, Redux Toolkit (RTK Query), SignalR, and Material UI.

---

## 📖 Overview

This project is a FBTI-Helpdesk designed to support real-time updates using SignalR and efficient API management via RTK Query.

It features:

- 🔄 Real-time synchronization between users (via SignalR)
- ⚡ Fast data fetching & caching (via RTK Query)
- 🎨 Responsive, modern UI (via Material UI)
- 🌙 Light & Dark mode support
- 🧱 Modular and scalable project structure

---

## 🏗️ Tech Stack

| Layer                       | Technology                |
| --------------------------- | ------------------------- |
| **Frontend**                | React JS (CRAP)           |
| **State Management**        | Redux Toolkit + RTK Query |
| **Real-time Communication** | SignalR                   |
| **UI Library**              | Material UI               |
| **Styling**                 | SASS / SCSS Modules       |
| **Routing**                 | React Router DOM          |
| **Form Handling**           | React Hook Form           |
| **Date Handling**           | Moment.js                 |
